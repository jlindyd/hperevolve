# HPE branding implementation

Reference: https://design-system.hpe.design/foundation/our-brand

- Landing page uses the unmodified positive HPE logo downloaded from the design system, paired with a separate ReVolve product label.
- Application uses the Element with HPE company and ReVolve product names at top-left.
- HPE Graphik Regular, Medium, Semibold, and Bold are loaded from the CDN URLs published in the Typography guidance, with Arial fallback and font-display: swap.
- Shared CSS semantic variables reflect the light theme: brand #01a982, primary #068667, hover #006750, back #f7f7f7, heading #292d3a, default text #3e4550, supporting text #606a70, weak border #d4d8db, selected/ok #d1ffee, warning #fff3dd, critical #ffecec, info #e3f1ff.
- Status labels and icons remain present so color is not the only indicator.
- Prototype/sample-data labels remain visible; this is not a claim of HPE approval or production readiness.
